# Livraria Simples 📚

Projeto simples de livraria desenvolvido para demonstrar o fluxo básico de colaboração com GitHub (branches, commits convencionais, Pull Request e merge).

## 📖 Catálogo Inicial de Livros

1. **Código Limpo** - Robert C. Martin (R$ 85,00)
2. **O Programador Pragmático** - Andrew Hunt & David Thomas (R$ 92,00)
3. **Entendendo Algoritmos** - Aditya Bhargava (R$ 64,00)

## 🚀 Como Executar

Abra o arquivo `index.html` em qualquer navegador web.
